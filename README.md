# 2027 九州親子旅行工具

換電腦或接續開發，先讀 [2026/11/19 交接文件](docs/HANDOFF-2026-11-19.md)：包含已完成內容、尚未實作的登入與同步需求，以及本機資料備份方式。

直接以瀏覽器開啟 `index.html` 即可使用，不需要地圖 API 金鑰、帳號或後端服務。

## 功能

- 五天共 43 個原始時段，以日期切換和垂直列表閱讀。列表只顯示時間、中文名稱、停留時間與照片；點卡片從底部開啟詳情。
- 收藏地點：貼 Google 地圖分享連結，可填名稱、備註，先收進「待安排」。短連結不會自動解析店名。
- 排入行程：選日期、時間與插入位置，可加入主行程，或附在某段行程下當備選。
- 編輯日期、時間、名稱、連結與備註；編輯與移除按鈕位於詳情底部；已移除往前／往後按鈕。
- 自訂行程移回待安排；移除主行程時，其備選也會回到待安排。修改可復原上一步。
- 各地點可在需要時開啟 Google 地圖。沒有內嵌地圖，不讀取或同步 Google 私人收藏。
- 右上角筆記本開啟 12 項出發前待辦，badge 顯示未完成數量，無負責人欄位。
- 日期使用「2/5 五」單行扁平 tab；右下角＋收藏新地點。
- 交通／纜車改成景點卡片間的小段落，預估時間取自原規劃預留時段，含可能的停車與手續，非即時導航。未知時間明確標示待確認。
- 2/5 BR104、2/9 AK1511 使用機票式卡片，分別標示兩地時間、起降機場與航廈待核對資訊，航班時刻可在詳情內編輯。
- 本機儲存，以及 JSON 匯出／匯入；匯入前檢查檔案格式及 Google 連結。

## 資料與使用限制

收藏、行程修改與勾選儲存在目前瀏覽器。不同網址、不同瀏覽器或家人的裝置不會自動共享更新。可匯出行程備份，交給家人匯入。清除瀏覽器資料前請先匯出。

境內時間為日本時間，台灣時段另標。停留時間依起訖時間自動計算；未填結束時間則標示未定，不額外推估。時間與住宿狀態沿用 2026/11/19 規劃，非預約。麵包超人與門司港保留在待安排；2/7 福岡或小倉住宿仍待決定。

## 檔案

- `index.html`：版面與表單。
- `trip-data.js`：原始規劃、圖片來源及待辦。
- `trip-core.js`：地點收藏、安排、編輯與資料檢查。
- `app.js`：畫面操作與瀏覽器儲存。
- `thumbs/`：15 張目前使用的素材。
- `docs/目前規劃與素材/`：保留最新 Word 原稿與素材對照供核對。

已移除內嵌地圖、API 金鑰設定頁、本機金鑰服務及其測試。網站曾建立部署識別，但上傳被中止，尚未完成正式發布；`.openai/hosting.json` 保留供日後沿用，未儲存金鑰。

## 驗證

執行 `node --test tests/trip-core.test.cjs` 檢查收藏、排入／移回、跨日修改、備選、連結驗證、備份匯入、交通時間分類與航班跨時區時長。
