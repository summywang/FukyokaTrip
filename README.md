# 2027 九州親子旅行工具

換電腦或接續開發，先讀 [2026/11/23 最新交接文件](docs/HANDOFF-2026-11-23.md)。11/19 的交接保留作歷史紀錄，現況以新版為準。

直接用瀏覽器開啟 `index.html`，或在專案目錄執行 `python3 -m http.server 5173 --bind 127.0.0.1` 後開啟 `http://127.0.0.1:5173/`。沒有套件安裝、帳號或 API 金鑰需求。

## 目前功能

- 五天垂直行程同頁閱讀，日期 tab 是錨點，捲動時標示當日。
- 由布院／小倉城版本切換替換 2/7–2/8。A 版原始 39 段；入境與取車合併顯示後為 38 段。B 版替換兩日共 17 段。
- 卡片顯示完整起訖時段（如 `16:55-19:00`）、中文標題、停留時間與正方形滿版圖片；不另列預計完成／離開。沒有結束時間的項目不補造時間。
- 交通、纜車呈現在卡片之間，顯示出發／抵達時間、預估時長與方式。
- 點卡片開固定 88dvh 高度的 bottom sheet，X 圖示關閉，內文獨立捲動。頂端「地點」使用地址連往 Google 地圖，原文字色搭配淺灰底線；未知餐廳只顯示待選區域。
- 詳情只留實用提醒，不顯示時間核實過程、估算依據或底部「當日住宿」說明。入住項目本身仍有住宿資料、照片與訂房連結。
- 航班保留機票式卡片，已去掉下半段的日期、航廈與核對提醒。
- 編輯、移除、收藏區及浮動＋入口暫時隱藏；功能程式仍保留。**這是畫面隱藏，不是登入權限保護。**
- 標題不使用 `｜` 或 `|`，也不把停車寫入標題；早餐／用餐／入住命名保持一致。
- 右上角筆記本有 14 項待辦，badge 顯示未完成數量；沒有負責人。
- 小倉版本內容最上方有差異說明框，淺色底與邊框、一般內文色、16px 文字；切到由布院版本時不顯示。
- 匯出／匯入 JSON、本機儲存及復原一步保留；備份會驗證格式與 Google 連結。

## 圖片與租車／住宿

- 去程 10:40 項目使用提供的長榮照片；回程候機項目使用亞航照片。
- 尚未選定餐廳的用餐項目使用提供的用餐插畫；門司港散策例外，使用最新港景照片。
- 「福岡抵達入境與租車」合併為 16:55–19:00，租車聯絡、地址與接駁資訊在其詳情。回程維持 13:00–13:30 提前還車。
- 四晚住宿在 `trip-data.js` 的 `lodgings`。D2 Casa Stay Kokura 1 位於小倉南區葛原東，D3 YUNOA 位於由布院；D1／D4 公開頁只有吉塚區域，未杜撰完整門牌。2/7 福岡備用住宿仍待安排。

## 資料與限制

使用目標是幫家人掌握停留長度，避免玩太久；時間允許合理概估，不能宣稱已核實所有車程。內部檢視與來源在 [時間核對紀錄](docs/TIME-REVIEW-2026-11-23.md)，**不要把核實過程加回行程詳情**。

資料存在目前瀏覽器的 `kyushu-2027-planner-v3`。不同電腦、瀏覽器、網址與家人裝置不會自動同步。換電腦前若有個人新增內容或勾選，請匯出 JSON 備份；GitHub 只攜帶程式、內建資料與素材。

尚未實作登入、共用雲端儲存、跨日拖曳、自動重新排時及 AI 重排；沒有內嵌地圖、Google／OpenAI API，也不會同步 Google 私人收藏。網站尚未完成正式發布，推 GitHub 不等於上線；既有未發布 Sites 識別保留在 `.openai/hosting.json`，不可重建成另一個專案。

## 程式與驗證

- `index.html`：頁面、樣式與表單。
- `trip-data.js`：行程、A／B 版、住宿、地址、素材、待辦與內部核對資料。
- `trip-core.js`：資料操作、備份驗證、時長換算與舊資料遷移。
- `app.js`：畫面、方案切換、日期錨點與瀏覽器儲存。
- `tests/trip-core.test.cjs`：16 項資料邏輯與遷移測試。
- `thumbs/`：本機圖片；部分住宿圖片仍引用訂房網站。
- `docs/目前規劃與素材/`：保留 11/19 原始規劃與素材，僅供追溯；現行 11/23 A／B 版以 `trip-data.js` 為準。

驗證：`node --test tests/trip-core.test.cjs`。
