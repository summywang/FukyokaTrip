# 2027 九州親子旅行工具

先讀 [接手規則](AGENTS.md) 與 [人員、用餐與行程基本資料](docs/PROJECT-BRIEF.md)，找餐廳或討論行程也適用。開發細節再讀 [2026/11/23 交接文件](docs/HANDOFF-2026-11-23.md)。11/19 原稿及歷史交接只供追溯。

公開網址：[2027 九州親子旅行](https://summywang.github.io/FukyokaTrip/)。2026/11/23 已發布第一晚五家餐廳小卡（`17e2b48`）；後續基本資料整理於 2026/11/24，是否已同步至 GitHub 須看該次提交狀態。

直接用瀏覽器開啟 `index.html`，或在專案目錄執行 `python3 -m http.server 5173 --bind 127.0.0.1` 後開啟 `http://127.0.0.1:5173/`。沒有套件安裝、帳號或 API 金鑰需求。

## 目前功能

- 五天垂直行程同頁閱讀，日期 tab 是錨點，捲動時標示當日。底部置中的「地圖」浮動按鈕在新分頁開啟使用者提供的 Google 我的地圖（A／B 共用）；沒有頁首地圖區塊。
- 由布院／小倉城版本切換替換 2/7–2/8。A 版原始 39 段；入境與取車合併顯示後為 38 段。B 版替換兩日共 17 段。
- 卡片顯示完整起訖時段（如 `17:00-19:00`）、中文標題、停留時間與正方形滿版圖片；不另列預計完成／離開。沒有結束時間的項目不補造時間。
- 交通、纜車呈現在卡片之間，顯示出發／抵達時間、預估時長與方式。
- 點卡片開**整頁式詳情**（2026/11/26 起，取代原 88dvh bottom sheet）：左上角「<」返回行程列表，手機返回手勢也會回到列表，內文獨立捲動。基本資料下方有「這段的日文」chips，點了從下方開出該情境的日文卡。頂端「地點」使用地址連往 Google 地圖，原文字色搭配淺灰底線；未知餐廳只顯示待選區域。
- 詳情只留實用提醒，不顯示時間核實過程、估算依據或底部「當日住宿」說明。入住項目本身仍有住宿資料、照片與訂房連結。
- 航班保留機票式卡片，已去掉下半段的日期、航廈與核對提醒。
- 編輯、移除、收藏區及浮動＋入口暫時隱藏；功能程式仍保留。**這是畫面隱藏，不是登入權限保護。**
- 標題不使用 `｜` 或 `|`，也不把停車寫入標題；早餐／用餐／入住命名保持一致。
- 右上角為可新增、編輯的出發前筆記：右滑顯示編輯、左滑顯示封存，已封存筆記可查看與還原。原 14 項待辦首次轉成筆記，已勾選項目轉為封存，不再顯示 checkbox；badge 顯示未封存筆記數。
- 小倉版本內容最上方有差異說明框，淡橘紅底與橘紅邊框、一般內文色、16px 文字；切到由布院版本時不顯示。
- 匯出／匯入 JSON、本機儲存及復原一步保留；備份含筆記與封存狀態，會驗證格式與 Google 連結。

## 資料與限制

使用目標是幫家人掌握停留長度，避免玩太久；時間允許合理概估，不能宣稱已核實所有車程。內部檢視與來源在 [時間核對紀錄](docs/TIME-REVIEW-2026-11-23.md)，**不要把核實過程加回行程詳情**。

資料存在目前瀏覽器的 `kyushu-2027-planner-v3`。不同電腦、瀏覽器、網址與家人裝置不會自動同步。換電腦前若有個人新增內容或勾選，請匯出 JSON 備份；GitHub 只攜帶程式、內建資料與素材。

尚未實作登入、共用雲端儲存、跨日拖曳、自動重新排時及 AI 重排；沒有內嵌地圖、Google／OpenAI API，也不會同步 Google 私人收藏。網站已使用 GitHub Pages（main 分支根目錄）發布；推送後仍須確認 Pages 部署成功。`.openai/hosting.json` 是舊 Sites 資訊，目前沿用上方 GitHub Pages 網址，不另建網站。

## 程式與驗證

- `index.html`：頁面、樣式與表單。
- `trip-data.js`：行程、A／B 版、住宿、地址、素材、待辦與內部核對資料。
- `trip-core.js`：資料操作、備份驗證、時長換算與舊資料遷移。
- `app.js`：畫面、方案切換、日期錨點與瀏覽器儲存。
- `dialog-history.js`：整頁詳情與 bottom sheet 開啟時寫入瀏覽器歷史，讓返回手勢依序關閉，不離開網站。
- `japanese/`：旅途日文。`phrases.js` 是全部句子，`jp-core.js` 是行程對應與素食卡邏輯，`words.js` 是點詞組的解說，`jp-ui.js` 是兩頁共用的日文卡 sheet、詞組提示框、放大畫面與語音，`jp-page.js`／`index.html` 是情境卡列表頁，`jp.css` 為共用樣式。
- `tests/trip-core.test.cjs`：資料邏輯與遷移測試；另有 `tests/notes.test.cjs` 驗證筆記遷移、編輯與封存備份；`tests/japanese.test.cjs` 驗證日文資料（每句都有日文、羅馬拼音、中文，漢字都有振假名、每個詞組都有點擊解說且讀音與振假名一致）、行程對應與素食卡。目前共 36 項。
- `thumbs/`：本機圖片；部分住宿圖片仍引用訂房網站。
- `docs/目前規劃與素材/`：保留 11/19 原始規劃與素材，僅供追溯；現行 11/23 A／B 版以 `trip-data.js` 為準。

驗證：`node --test tests/*.test.cjs`。

筆記與行程仍僅存在目前瀏覽器；新增／編輯筆記不需要登入，不代表已完成先前討論的雲端權限功能。筆記使用 `state.notes`，舊 `state.done` 只作歷史相容；編輯對話框同為 88dvh。

Bottom sheet 支援從頂部把手／標題區向下拖曳關閉，內容已捲到最上方時也可下拉關閉；短距離會彈回，表單控制項與筆記左右滑不觸發關閉。以 touchmove 與捲動邊界設定抑制原生下拉重新整理。X 不顯示橘色 focus 外框，鍵盤焦點改用淺底色；備案天候提醒移至內容區橘紅框上方、16px 粗體。`sheet-gestures.js` 為獨立手勢模組，新增 3 項行為測試，目前總共 22 項。

筆記最新改為滿版寬的列表，以水平分隔線區隔，移除卡片圓角／間距與「⋯」。左右滑及鍵盤方向鍵操作保留。使用者正在討論未來部署為公開家人行程版＋登入保護的私人管理／筆記版，尚未實作；私人筆記不可包含在公開版本資料中，兩版應共用行程以避免重複維護。

## 旅途日文（2026/11/26，本機預覽，尚未發布）

- 入口：首頁右上角「あ」（筆記按鈕左邊）開 `japanese/`；每段行程的整頁詳情也有「這段的日文」chips。使用者只有自己用、會五十音，所以**每句固定是：日文大字（漢字上標振假名）、羅馬拼音、中文小字**，點「播放／慢速」用手機內建日文語音，「放大」全螢幕給對方看。沒有 API、登入或網路請求。
- 排版依使用者 2026/11/26 提供的歌詞 App 參考：整句置中，句子切成詞組，振假名在上、**羅馬拼音對齊在每個詞組正下方**、中文置中在最下面。資料格式：`ja` 用半形空格分詞組、`ro` 用「 / 」分詞組，兩邊數量必須一致（測試會檢查）。
- **點詞組看解說**（同參考專案 `summywang/fujiikaze-lyricbook` 的規格）：詞組反白、用手機語音唸出，深色提示框列出讀音、慣用語／口語／方言標籤、白話意思、拆開的每個部分（漢字附讀音）與「句型」。點別處或 Esc 關閉，捲動時跟著詞組。解說在 `japanese/words.js`，以詞組去掉句尾標點的文字為鍵；寫法規則同參考專案 `work/breakdown/README.md`（白話、不用文法術語、同一助詞全站同一句說明）。測試會檢查每個詞組都有解說、拆開的部分拼回原詞組、讀音和振假名一致。放大給對方看的畫面不能點詞組。
- 振假名改用疊放方框（`.furi`／`.furi-rt`），不用 `<ruby>`：參考專案記錄過新版 iPhone Safari 會讓有振假名的詞底下多出空間，羅馬拼音因此不齊。字級沿用參考專案：日文 clamp(22px,4.6vw,30px) 粗體、振假名與羅馬拼音 16px、中文 16px。
- 齒輪（日文頁標題列、日文卡與放大畫面右上）開「顯示設定」：振假名、羅馬拼音、中文翻譯三個開關，預設全開，存於 `kyushu-2027-japanese-display-v1`；以 `<html data-jp-*>` 切換，放大畫面也套用。
- `japanese/` 是一頁情境卡，沒有分頁：依行程第一次用到的順序排，卡片小字顯示哪幾天、幾段行程會用到；寶寶、緊急、基本會話放在最後「隨時用得到」。2/5–2/9 期間（日本時間）會把「現在／下一段」用得到的卡移到最上面。預覽可加 `?now=2027-02-06T10:30`。
- 行程對應寫在 `jp-core.js` 的 `scenariosForSlot`，用行程**標題關鍵字**判斷，所以 A／B 切換、改名都會跟著走；日文頁唯讀主網站的 `kyushu-2027-planner-v3`，不會寫回。2/7–2/8 的開車段固定附「雪天路況」。
- 「餐廳用餐與素食說明」卡最上面是給店員看的素食說明，內容依 AGENTS.md：不吃肉魚海鮮、魚／肉高湯與動物性調味料也不行、五辛可以。**蛋、奶、共用鍋具、素食人數預設「未設定」，未設定時卡片完全不提**；使用者在手機上設定後才加入，存於 `kyushu-2027-japanese-v1`（只在該瀏覽器）。成分表的蛋奶標籤也跟著這個設定。
