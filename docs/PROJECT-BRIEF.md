## 先知道這幾件事

- 2027/2/5（五）–2/9（二），九州五天四夜，以福岡進出、租車自駕。
- **5 位大人＋1 位旅途中約 1.5 歲的寶寶，共 6 人**，包含長輩。現有規劃提到使用者、先生、公公、婆婆、小叔與寶寶；不要再問基本人數，也不要自行推定每個人的年齡、體力或飲食身分。
- 同團有葷食與五辛素需求；**素食連魚／肉高湯、柴魚等動物調味都不能有**。素食人數、蛋奶與共鍋接受程度尚未確定，不能把所有長輩都當成同一種飲食。
- 每位成人每餐 **NT$1,500 內，含稅與必要費用**；Google Maps **4.0 星以上**。一般不限定料理類型，只有第一晚除夕原希望日式、吃好一些有慶祝感。
- 主線是「由布院版本」；「小倉城版本 (備案)」用於由布院大雪／道路不宜通行時，替換 2/7–2/8。不要把兩版景點全部排在同一天。
- 工具目的是旅行當下看起訖時間、控制停留，避免玩太久。可合理概估，不必把每天排滿，也不能宣稱所有車程已精算。
- 公開網站已上線：[行程網站](https://summywang.github.io/FukyokaTrip/)。GitHub 是 [summywang/FukyokaTrip](https://github.com/summywang/FukyokaTrip)，main 分支根目錄部署。

## 找餐廳的固定做法

完整用餐規則在根目錄 `AGENTS.md`；適用所有午晚餐與後續重排，不只第一天。

1. 先讀當日 A／B 動線、用餐時段、住宿區域；選 3–5 家附近候選，避免繞遠路與過度緊湊。
2. 預設同桌能安排葷食與完整五辛素餐，不需專門素食餐廳。五辛可；魚肉海鮮、魚／肉高湯、柴魚、魚粉、雞粉、豬骨湯、蠔油、蝦醬、豬油等不行。日本味噌湯、豆皮壽司、青菜不能只憑菜名判定合格。
3. Google Maps 至少 4.0 星，直接核對並記錄日期與評論數；不能用別的平台分數冒充。每家必給 **Google Maps 連結**，菜單、官網、訂位另外給。
4. 每位成人完整一餐含稅、必要服務費／座位費上限 NT$1,500，依查詢時匯率並留餘裕。不只用最低價配菜，也不靠全桌平均掩蓋超支；不預設喝酒。
5. 具體說明葷食與素食各能怎麼吃、價格、地址、與行程的關係、寶寶接待／座位資訊。分清已核實菜單、可詢問替換與尚待店家確認。
6. 依實際用餐日期提供建議；網站訂位說明只有「訂位資訊」（建議訂位時間＋訂位／詢問方式）與「訂位時告知」（保留既有需求）兩欄，不另顯示期限。正式期限留內部資料；**我方建議不是店家公告**，不能捏造空位、特殊日營業或客製確認。
7. 加進網站時維持可展開小卡：店名、料理類型、正方形封面；展開再給照片與全部資訊。加入「候選」不等於更換行程、選定或訂位。

## 安排行程時的偏好與待辦

- 親子＋長輩步調，留用餐、午睡、休息、上下車與接駁餘裕；以好跟行程、不要不小心玩太久為目標。
- 使用者接受合理概估。完整時間核實、矛盾與來源留內部文件，不放回公開詳情的長篇估時解釋；涉及選擇的實際限制仍應簡潔交代。
- 麵包超人博物館在內建待辦標為必去，但**目前沒有排進主線**；重排時提出替換方案，不偷偷塞滿。
- 海洋世界在既有研究中記錄 2027/1/12–4/9 劇場秀整修，不能承諾 2/6 有海豚跳躍秀；重新安排前核對官網當期公告。鋼彈、纜車、湯屋與冬季道路亦按旅遊日期核對。
- 尚待決定：其餘各餐、餐廳實際葷素份數、A 版由布院晚餐、B 版 2/7 福岡備用住宿、家族湯屋訂位、完整機票與租車門市／時間協調。
- 不要問使用者已提供的人數、日期、預算、湯底規則；先讀文件與資料。真正缺少且影響選擇的資訊才詢問，查不到精確地址可依使用者接受的區域概估繼續。

## 其他 AI 怎麼接手

1. **先讀根目錄 `AGENTS.md` 與本檔，再回答。** 改畫面或資料邏輯才接著讀 `README.md` 與 `docs/HANDOFF-2026-11-23.md`；查時間來源讀 `docs/TIME-REVIEW-2026-11-23.md`。
2. 需求優先序：使用者最新明確指示 → 現行基本資料／規則 → `trip-data.js` 的當前 A／B 資料與合併規則 → 歷史交接／原稿。遇到矛盾先核對，不恢復舊版設計或把早期候選當定案。
3. 文件只能讓讀得到此專案檔案的 session 接手；不同帳號或另一台電腦，須取得含這份文件的最新專案版本。既有 session 不會自動知道檔案更新，請它重新讀取 `AGENTS.md` 與本檔。無專案存取權的普通聊天，需提供本檔內容；不要宣稱跨帳號記憶已同步。
