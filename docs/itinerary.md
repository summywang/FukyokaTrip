# 2027 九州春節親子旅行｜持續更新行程表

更新日期：2026/11/15（台灣時間）｜版本：第 3 版

## 行程設定

- 日期：2027/2/5（五）～2/9（二）；表內皆為日本時間。
- 航班：2/5 16:55 抵達福岡；2/9 16:40 離開福岡。
- 成員：5 位成人＋1 位約一歲半寶寶，含長輩；4 位成人會開車，其中 1 位有雪地經驗。可在日本駕駛資格及租車登記仍待確認。
- 主軸：熊本市、由布院溫泉、天神購物；不另排北九州市。
- 交通草案：2/6 早上福岡取車，2/8 下午回福岡還車。車型需確認 5 大 1 小、安全座椅、推車及行李皆能容納，預訂冬胎並確認雪鏈。
- 住宿草案：2/5 博多 → 2/6 熊本市區 → 2/7 由布院 → 2/8 天神。尚未指定或預訂飯店。
- 使用方式：「其他選項」與「雨備」是替換，並非全部疊加。時間為規劃估算，午睡跟隨寶寶作息；訂房、租車與營業時間確認後再細修。

## 選項狀態與取捨

- 阿蘇僅作 2/7 熊本→由布院的路線備選：天氣晴朗、道路確認適合通行時，考慮經阿蘇地區，於道之驛阿蘇短停約 20～30 分鐘遠看阿蘇五岳；不特地上草千里或中岳火口。不是固定新增景點，主行程與住宿不變。前一天及當日依路況決定，若有積雪、結冰、濃霧就不為看山選此線；高速公路也須查核。採用時須重新確認車程，必要時縮短由布院逛街，保留入住休息時間。


- 已確認備案：由布院若因天候取消，再考慮用 MARINE WORLD 海之中道水族館補上福岡的一天；不加入原主行程，不另加海濱公園。
- 替代動線草案：2/7 熊本返回福岡、入住休息；2/8 水族館半日，再回市區還車／逛天神。需確認福岡道路與館方營運、由布院取消條件、增加福岡住宿及租車安排；尚未預訂。

## 冬季天氣與交通備案

二月上旬平年日最高／最低：福岡 10.4／3.7°C、熊本 11.1／1.5°C、由布院 7.6／−2.3°C（日本氣象廳 1991～2020 平年值，並非 2027 年預報）。

小雪不等於必須取消，也不等於道路安全。確認冬胎、攜帶合適雪鏈，由有經驗駕駛評估；白天抵達。前一晚及出發當天查看官方道路資訊，再詢問旅館最後一段道路、入口坡度及結冰情況。若持續大雪、封路或隔日回程預報明顯惡化，考慮取消由布院、提早回福岡，先確認住宿取消條件。高速公路封閉時不自行改走不熟悉山路。一般下雨的室內雨備不能替代交通安全評估。
