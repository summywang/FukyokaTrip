- `index.html`：樣式、dialog、隱藏入口；JS 資源帶版本 query 避免預覽使用舊快取。

- `app.js`：日期錨點、方案切換、完整時間顯示、`locationInfo/locationRow`、bottom sheet、租車資訊及版本說明框。
- `trip-core.js`：資料操作與遷移。`refreshPhotos` 更新未被自訂的原始項目；`renamed`、`noteUpdates`、`slotUpdates`、`urlUpdates` 是有條件的遷移，避免粗暴覆蓋家人修改。改原始 ID 或刪原始段落前要先考慮本機舊資料。
