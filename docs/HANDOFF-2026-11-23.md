## 程式入口與遷移

- `index.html`：樣式、dialog、隱藏入口；JS 資源帶版本 query 避免預覽使用舊快取。
- `trip-data.js`：25 個素材 metadata、A／B 版、四晚住宿、14 待辦、`locations`、`displayNotes`、`rental` 與內部 `timeReview`。
- `app.js`：日期錨點、方案切換、完整時間顯示、`locationInfo/locationRow`、bottom sheet、租車資訊及版本說明框。
- `trip-core.js`：資料操作與遷移。`refreshPhotos` 更新未被自訂的原始項目；`renamed`、`noteUpdates`、`slotUpdates`、`urlUpdates` 是有條件的遷移，避免粗暴覆蓋家人修改。改原始 ID 或刪原始段落前要先考慮本機舊資料。
- localStorage 鍵：`kyushu-2027-planner-v3`，讀取舊鍵 v2／v1 遷移。A／B 未顯示的兩天在 `altDays`，不可遺漏備份驗證。
- `tests/trip-core.test.cjs`：16 項測試；本次新增來源修正的遷移測試，確保原始入境時間／住宿地圖連結更新、個人改過的時間保留。

預覽曾因舊快取顯示上版；先確認 server 的來源目錄正確、更新資源版本及刷新。使用者選中的版本與日期保留在目前瀏覽器，跟 GitHub 不同。
